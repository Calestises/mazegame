

一、软件简介
本程序是一个使用 C 语言编写的 Windows 控制台迷宫游戏。
玩家需要在随机生成的迷宫中移动，收集全部钥匙，最后到达门的位置完成通关。


二、运行环境
1. 操作系统
Windows

2. 运行方式
双击 exe 文件运行，或在终端中运行程序。

3. 说明
本程序使用 Windows 控制台功能，不适用于 Linux 或 macOS 终端直接运行。


三、启动程序
程序启动后，会显示开始菜单：

1. 新游戏
2. 读取存档

输入说明：
1. 输入 1：开始一局新游戏
2. 输入 2：尝试读取之前的存档

如果选择读取存档但存档不存在，程序会自动开始一局新游戏。


四、游戏界面说明
程序运行后，界面主要包括以下内容：

1. 标题区
显示当前游戏名称。

2. 状态区
显示当前钥匙收集进度。
例如：
钥匙:1/2

表示玩家已获得 1 把钥匙，总共需要获得 2 把钥匙。

3. 操作提示区
显示可使用的按键。

4. 图例区
显示各个字符的含义。

5. 地图区
显示当前迷宫地图和玩家位置。


五、符号说明
地图中会出现以下内容：

1. █：墙，不能通过
2. 空格：道路，可以通过
3. @：玩家当前位置
4. K：钥匙
5. D：门
6. O：传送点


六、按键操作
游戏中的操作如下：

1. w：向上移动
2. s：向下移动
3. a：向左移动
4. d：向右移动
5. p：保存当前游戏
6. o：读取存档
7. q：退出游戏

说明：
移动时不需要按回车，按键后会直接生效。


七、游戏规则
1. 基本规则
玩家从迷宫起点出发，在地图中寻找钥匙和出口。

2. 墙壁规则
墙不能通过。
如果朝墙方向移动，玩家位置不会改变。

3. 钥匙规则
玩家走到钥匙位置时，会自动拾取钥匙。
钥匙被拾取后会从地图中消失。

4. 门规则
玩家必须收集全部钥匙，才能进入门。
如果钥匙没有拿齐，即使移动到门前，也无法通过。

5. 传送点规则
玩家踩到传送点后，会被自动传送到另一个传送点位置。

6. 通关规则
当玩家收集完全部钥匙，并成功进入门后，游戏胜利。
程序会显示胜利信息。


八、存档与读档
1. 保存游戏
在游戏过程中按 p，可保存当前进度。

2. 读取存档
可通过两种方式读档：
1. 程序启动时选择“读取存档”
2. 游戏过程中按 o

3. 存档说明
当前版本默认使用一份存档文件。
再次保存时，会覆盖之前的同名存档。


九、通关后表现
通关后程序会显示：
1. You Win!
2. 你成功逃出了迷宫

随后程序会等待用户按键，再结束运行。


十、常见使用说明
1. 为什么窗口里是字符，不是图形界面？
因为本程序是控制台程序，使用字符绘制迷宫，不是图形化窗口程序。

2. 为什么按键后不用回车？
因为程序使用了直接读键方式，按下 wasd 后会立即响应。

3. 为什么每次新游戏地图不一样？
因为程序使用了随机迷宫生成逻辑。

4. 为什么有时读档失败？
可能原因包括：
1. 没有可用存档
2. 存档文件被删除
3. 存档文件内容损坏

如果启动时选择读档但失败，程序会自动开始新游戏。


十一、注意事项
1. 本程序仅支持 Windows 控制台环境。

2. 若使用终端运行，请保证终端能正常显示 UTF-8 字符，否则墙体字符可能显示异常。

3. 存档文件与程序文件放在同一路径下时，使用最稳定。


十二、总结
本程序是一款基础迷宫游戏，玩法简单明确：
1. 进入迷宫
2. 收集所有钥匙
3. 找到并进入门
4. 完成通关
